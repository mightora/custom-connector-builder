            How this works
            
Edit C# and fixtures, then run a mock transformation or compile with experimental in-browser Roslyn. No source is sent to a compiler service.

Experimental C# compiler · Runs in your browser
Compile and run real C# using Roslyn and .NET WebAssembly. First use downloads about 40 MB of runtime assets. A limited ScriptBase and JObject test adapter is provided; this is not Microsoft's hosted connector runtime. Browser workers are not a security sandbox; do not paste secrets or untrusted scripts.
